# HraSkritek

**Skřítkův skok** – 2D běhací hra v prohlížeči. Skřítek Bukvice běží večerním lesem a přeskakuje pařezy, kameny, muchomůrky a netopýry a podlézá pavučiny. Cestou sbírá borůvky.

## Jak hrát

Otevři `index.html` v prohlížeči. Hra funguje na počítači i na mobilu.

| Akce | Mobil | Počítač |
|---|---|---|
| Skok | ťuknutí | mezerník / šipka nahoru / W |
| Vyšší skok | podržet prst | podržet klávesu |
| Dvojskok | druhé ťuknutí ve vzduchu | druhý stisk ve vzduchu |
| Podlézt | držet tlačítko **Podlez** vlevo dole | držet šipku dolů / S |
| Pauza | tlačítko vpravo nahoře | P nebo Esc |

Skóre = metry + 10 za každou borůvku. Nejlepší skóre se ukládá v prohlížeči.
